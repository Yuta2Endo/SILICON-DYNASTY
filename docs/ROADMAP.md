# Roadmap — 14 stages

Execute one stage at a time. Audit the repository first, preserve user changes, avoid destructive Git commands, run available checks, write a report and stop for approval.

1. **Foundation & Design System** — React/TS/Vite, navigation, corporate UI, RU/EN, dashboard, company model, Simulation Core foundation, storage interface.
2. **CPU Designer** — ISA, architecture, cores/threads, clocks, IPC, cache, memory, power, projects, versions and validation.
3. **Simulation & Benchmark** — deterministic CPU/GPU workload, memory, power, temperature and throttling.
4. **Research & Timeline** — tech tree, dependencies, progress, eras and unlocks.
5. **Economy & Market** — finances, cost, pricing, manufacturing, sales, segments, competitors and market share.
6. **GPU & Components** — GPU, RAM, SSD, motherboard, AI accelerators, networking, compatibility and benchmarks.
7. **OS Architecture & Kernel Lab** — OS projects, kernel types, bootloader, scheduler, memory, IPC, syscalls and modules.
8. **OS Systems & Drivers** — filesystems, drivers, networking, security, permissions, encryption, updates, package manager and diagnostics.
9. **OS Interface & Software Ecosystem** — desktop/mobile/server profiles, GUI, SDK, API, IDE, app store, applications and releases.
10. **AI Architecture & Data Lab** — AI projects, architectures, model parameters, datasets, data quality and hardware requirements.
11. **AI Training & Deployment** — simulated training, metrics, costs, optimization, evaluation and deployment.
12. **Devices & Ecosystem Integration** — device configurator, OS/AI integration, cloud and synergy.
13. **Save System & Game Experience** — slots, autosave, import/export, backup, recovery, migrations, tutorial, achievements, events and long-session QA.
14. **Android Release & Final QA** — Capacitor, Android optimization, device testing, performance, memory, APK/AAB and release docs.

Each stage must create `docs/stages/STAGE_XX_REPORT.md` with scope, changed files, architecture decisions, exact test results, build result, acceptance status, blockers and next-step recommendation. Do not mark COMPLETED if mandatory criteria are unverified.
